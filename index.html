上手

三步装进游戏。

下载 .pmod

从对应详情页或 GitHub Release 下载 .pmod 文件。 部分 Mod 内含托管插件（Runtime/ModAssembly.dll），已一并打包。

放进 Mods 目录

把 .pmod 放入游戏的 Mods/ 目录，并在 enabled_mods.json 中登记启用。

重启游戏

重启客户端使 Mod 生效。ModsCache 由游戏自动管理，无需手动清理。

常见问题

装不上、没效果，先看这里。

装好后图鉴里出现重复条目怎么办？

这是新增角色时图鉴的去重规则所致。植物页重复需从 ModPlants 中摘出多余条目；僵尸页则依靠运行期去重。 各 Mod 的详情页会在「实现要点」里标注是否已处理。

说明文字显示成键名（如 zombie.xxx.name）？

因为翻译表在部分构建里不会被加载。稳妥做法是把文案直接写中文字面量， 而不是依赖翻译键。本站所有 Mod 均采用中文字面量。

Mod 生效了但动画/贴图不对？

自制 .dat 外观需要同时开启 forceLocalRender 与 forceCpuPoseRender，否则会走引擎默认渲染路径。

这些 Mod 会改动游戏本体文件吗？

不会。全部通过 .pmod 包以「覆盖 / 提供」两种方式挂载， 移除 .pmod 后游戏即回到原状。
